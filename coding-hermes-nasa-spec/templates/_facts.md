# Facts ledger

Every number the document prints, every behaviour it asserts, gets a row here.
Confidence classes: `measured`, `read-from-code`, `told-by-operator`, `assumed`.
An `assumed` fact cannot back a normative statement — convert it or mark the
statement a spike.

| id | claim | how measured (command / path / store) | measured at | confidence |
|---|---|---|---|---|
| FACT-01 | <claim with a unit> | `<exact command or file:line>` | <ISO timestamp> | measured |
